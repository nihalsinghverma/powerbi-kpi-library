# Power BI KPI Library

## Problem

Reusable KPI definitions are often scattered across reports, making business logic difficult to govern and maintain.

## What's included

Power BI KPI patterns, DAX measures, calculation-group examples, naming conventions, and validation notes.

## How to run

Clone the repository and follow the instructions in its examples or project files. Python examples use Python 3.11+ and should be run from an isolated virtual environment.

`powershell
git clone https://github.com/nihalsinghverma/powerbi-kpi-library.git
cd powerbi-kpi-library
`

## Outputs

Reusable DAX measures, KPI documentation, and report-ready modeling patterns.

## Design notes

Measures prioritize clear filter context, explicit assumptions, and consistent semantic-model conventions.

## Roadmap

Add industry-specific KPI packs, automated measure tests, and deployment examples.
